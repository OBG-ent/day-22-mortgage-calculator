# 🏠 Mortgage Calculator

**Know your real monthly payment before you sign anything.**

Enter a home price, down payment, interest rate, and amortization period, and instantly see your monthly payment, total interest paid, and a year-by-year amortization schedule showing exactly how your balance shrinks over time.

## ✨ Features

- Monthly payment calculation using the standard fixed-rate loan formula
- Total interest and amount-borrowed breakdown
- Year-by-year amortization table (principal vs. interest paid each year)
- Input validation with a friendly error message
- Results calculate automatically on page load

## 🚀 Run it in 30 seconds

No build step, no dependencies — just open the file:

1. Download or clone this repo
2. Open `index.html` in any browser

Try this: set the home price to **$650,000**, down payment to **$130,000**, rate to **5.5%**, and 25 years — watch how much of the total is interest.

## 🧠 What this project practices

- Reading and validating form input in JavaScript
- Math formulas and `Math.pow`
- Looping and simulating payments month by month
- Rendering dynamic tables with the DOM
- Currency formatting with `toLocaleString`

## 🛠 Tech

HTML · CSS · Vanilla JavaScript
